# Kozhi Meter 🐔📸

### Project Description
Kozhi Meter is a webapp that scans your face — via live laptop camera, mobile selfie camera, or an uploaded photo — and instantly reveals your official "Kozhi Score," a completely unscientific, wildly entertaining measure of just how much of a "vayanokki" you really are.

### The Problem (that doesn't exist)
Nobody has ever been able to quantify, with a satisfying percentage and a dramatic gauge animation, exactly how much of a certified "kozhi" a person is. Society has survived without this number for far too long.

### The Solution (that nobody asked for)
We point a camera at your face, run it through some very serious-looking (but entirely for-fun) detection logic, and spit out a bold, shareable "Kozhi Score" complete with a funny title, a bilingual roast, and a downloadable result card — so you can prove to your friends, once and for all, who the real vayanokki is.

## Technical Details
### Technologies/Components Used
For Software:
- TypeScript, JavaScript, HTML, CSS
- React + Vite
- Tailwind CSS
- Framer Motion (for the score-reveal animations)
- face-api.js / MediaPipe Face Landmarker (on-device face detection)
- Canvas API (for generating the shareable result card)

For Hardware:
- Laptop with a built-in or USB webcam
- Smartphone with a front (selfie) camera
- No additional hardware/sensors required
